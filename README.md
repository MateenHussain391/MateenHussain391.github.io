PORTFOLIO WEBSITE — QUICK START

Files:
- index.html  = page content and sections
- style.css   = design and responsive layout
- script.js   = mobile menu, active navigation, copyright year

BEFORE PUBLISHING:
1. Open index.html and replace every "Muhammad Mateen" / "YOUR NAME" with your name.
2. Replace your.email@example.com with your real email address.
3. Replace the GitHub and LinkedIn profile links with your own profile URLs.
4. In Education, enter your exact university, degree, and dates.
5. Update project descriptions and replace sample GitHub project links with real links.
6. Optional: change the "YN" letters in the profile circle to your initials.
7. Save all files. Keep all three files in the same folder.

PUBLISH WITH GITHUB PAGES:
1. Sign in at https://github.com/
2. Create a NEW PUBLIC repository. To get the exact username-style URL,
   name the repository exactly: YOUR-GITHUB-USERNAME.github.io
   (replace that text with your actual GitHub username).
3. Upload index.html, style.css, and script.js directly into the repository root.
4. Click Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then click Save.
7. Wait a few minutes and refresh the Pages section. Open the published URL:
   https://YOUR-GITHUB-USERNAME.github.io/
8. Test every menu link and contact/social link.

NOTE:
- GitHub username and repository name are not the same thing as your display name.
- The website URL may take a few minutes to become available after publishing.
- A real email address and real profile links are needed for those buttons to work.
